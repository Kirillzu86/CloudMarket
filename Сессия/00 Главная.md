# Сессия по проекту CloudMarket

Материалы для выступления:

- [[01 Речь для презентации]]
- [[02 Ключевые тезисы]]

Проект: интернет-магазин `CloudMarket`

Стек:
- Frontend: `React + Vite + TypeScript`
- Backend: `FastAPI + SQLAlchemy + SQLite`

Основная идея:
Создать современный онлайн-магазин с удобным интерфейсом, каталогом товаров, карточками продуктов, авторизацией и готовой клиент-серверной архитектурой.
