# Речь для презентации

## Короткая версия на 2-3 минуты

Здравствуйте. Я представляю проект **CloudMarket** - это современный интернет-магазин, разработанный по клиент-серверной архитектуре.

На фронтенде я использовал **React**, **Vite** и **TypeScript**, а на бэкенде - **FastAPI**, **SQLAlchemy** и **SQLite**. Такое решение позволило разделить пользовательский интерфейс и серверную логику, а также организовать удобную работу с данными.

В проекте реализованы основные возможности интернет-магазина: главная страница с витриной товаров, каталог, детальная страница продукта, регистрация и вход пользователя, а также персональные разделы, например корзина и избранное.

Каталог получает данные через API, которое обрабатывается на сервере. При этом в проекте предусмотрен fallback-механизм: если данные с сервера недоступны, интерфейс может использовать локальный каталог. Это делает приложение более устойчивым.

На сервере реализованы маршруты для получения списка товаров, получения товара по `slug`, регистрации, авторизации и получения информации о текущем пользователе. Таким образом, проект демонстрирует не только красивый интерфейс, но и полноценное взаимодействие между клиентом и сервером.

Сильной стороной проекта я считаю современную структуру, разделение ответственности между фронтендом и бэкендом, а также возможность дальнейшего масштабирования. Например, в будущем сюда можно добавить онлайн-оплату, фильтрацию, панель администратора и историю заказов.

В итоге CloudMarket - это полноценный учебный проект, который показывает навыки создания интерфейсов, настройки API, работы с базой данных и построения архитектуры веб-приложения.

Спасибо за внимание.

## Если спросят "почему этот проект хороший"

Можно ответить так:

Проект хороший, потому что он решает реальную прикладную задачу и при этом охватывает сразу несколько важных направлений разработки: интерфейс, сервер, базу данных, авторизацию и взаимодействие через API. То есть это не отдельная страница и не отдельный сервер, а полноценная система.
