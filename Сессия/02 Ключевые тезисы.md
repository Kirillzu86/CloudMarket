# Ключевые тезисы

## Что сказать в начале

- CloudMarket - это проект современного интернет-магазина.
- Цель проекта - создать удобное веб-приложение с клиентской и серверной частью.
- Проект показывает полный цикл взаимодействия между интерфейсом, API и базой данных.

## Технологии

- `React + Vite + TypeScript` для фронтенда.
- `FastAPI + SQLAlchemy + SQLite` для бэкенда.
- `React Router` для маршрутизации.
- `JWT`-подобная токен-авторизация для входа пользователя.

## Что реализовано

- Главная страница магазина.
- Каталог товаров.
- Детальная страница продукта.
- Регистрация и вход.
- Получение текущего пользователя.
- Корзина, избранное и личный раздел.
- API для работы с товарами и авторизацией.

## Сильные стороны проекта

- Разделение фронтенда и бэкенда.
- Современный стек.
- Понятная структура компонентов и маршрутов.
- Наличие базы данных и серверной логики.
- Возможность локального запуска и деплоя.
- Есть fallback для каталога, если API недоступен.

## Что можно сказать в конце

- Проект можно развивать дальше.
- Можно добавить оплату, фильтры, историю заказов и админ-панель.
- CloudMarket показывает практические навыки fullstack-разработки.
